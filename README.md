# Homebrew Tap for Lernstoff Wiki

Homebrew tap for [Lernstoff Wiki](https://github.com/JsonLee12138/lernstoff-wiki) — Headless Cognitive Selective Note-Taking Engine & Daemon for AI Agents and Obsidian.

## Installation

```bash
brew tap JsonLee12138/lernstoff-wiki
brew install lernstoff
```

Or install directly in one step:

```bash
brew install JsonLee12138/lernstoff-wiki/lernstoff
```

## Update

```bash
brew upgrade lernstoff
```
